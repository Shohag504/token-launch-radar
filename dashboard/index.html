How the value is figured

implied = TVL × category multiple × growth × maturity × breadth

  • Category multiple — the median market-cap / TVL of the live-token protocols in the same category, measured from this snapshot (clamped 0.05–1.5; thin categories use the global median). A lending protocol is priced like lending protocols that already trade, not like a bridge.
  • Growth — 1 + (7-day TVL change, clamped −50%…+150%) × 0.6. A protocol growing fast is worth more than one shrinking at the same size.
  • Maturity — 0.7 + age/1095 × 0.3 (0.85 when no listing date is recorded). A protocol that ran three years with no token has a longer record behind the same TVL.
  • Breadth — 1 + 0.05 × (chains − 1, capped at 4). More chains, more farmers reached.

Every row is scored by the same formula — no protocol name is ever special-cased. The watchlist ($50M+ TVL, no token recorded) is the floor, never the ceiling: the board also ranks the early finds below it.
